# عقار السعودية — منصة عقارية كاملة

منصة Next.js + Prisma + SQLite مع واجهة عربية RTL ولوحة تحكم محمية بتسجيل دخول ورفع صور.

## المزايا
- الصفحة الرئيسية + بحث.
- أحياء مستقلة: الرمال، النرجس، الياسمين، الملقا، العارض وغيرها.
- داخل كل حي تظهر العقارات.
- أنواع العقارات: شقق، فلل، أراضي، أدوار.
- بيع / إيجار.
- صفحة تفاصيل لكل عقار.
- معرض صور متعدد لكل عقار.
- لوحة تحكم للمالك: إضافة، تعديل، حذف، تمييز، صور، أحياء.
- قاعدة بيانات SQLite حقيقية عبر Prisma وليست LocalStorage.
- جلسة دخول آمنة عبر HttpOnly cookie وJWT.
- تصميم متجاوب للجوال والكمبيوتر.

## التشغيل المحلي

1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. عدّل `JWT_SECRET` وكلمة مرور المدير.
4. نفّذ:

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

ثم افتح:
`http://localhost:3000`

لوحة التحكم:
`http://localhost:3000/admin`

بيانات الدخول الافتراضية في المثال:
- البريد: `admin@example.com`
- كلمة المرور: `ChangeMe123!`

**غيّرها قبل النشر.**

## ملاحظات الصور
الصور تُحفظ داخل `public/uploads`. هذا مناسب للتجربة وعلى VPS، لكن عند التوسع يُفضّل نقل الصور إلى خدمة تخزين مثل S3-compatible storage أو Cloudinary.

## النشر
### خيار VPS
هذا المشروع مناسب لـ VPS لأنه يستطيع تشغيل Next.js والـ SQLite والملفات المرفوعة على نفس الخادم.

بعد رفع المشروع:

```bash
npm install
npm run db:push
npm run db:seed
npm run build
npm start
```

استخدم Nginx أو Caddy أمام التطبيق واربط الدومين بالخادم مع HTTPS.

### خيار Postgres + Storage
للإنتاج الكبير يمكن تغيير Prisma datasource إلى PostgreSQL ونقل الصور إلى Object Storage، مع الإبقاء على نفس الواجهة ولوحة التحكم.

## الدومين
بعد شراء الدومين، أنشئ DNS A record يشير إلى IP الخادم، ثم اضبط Nginx/Caddy على الدومين. مثال:
`A @ -> IP-ADDRESS`

لا تحتاج لتغيير روابط الموقع داخل الكود؛ استخدم الدومين في إعدادات الاستضافة وHTTPS.
